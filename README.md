# personaLearn

Platform e-learning dengan rekomendasi konten pembelajaran yang dipersonalisasi berdasarkan kepribadian dan gaya belajar (MBTI, Big Five, VARK), dilengkapi bantuan belajar AI.

## Tentang Proyek

personaLearn adalah Tugas Besar IPPL Kelompok 8 Telkom University yang berfokus pada:

- Personalisasi pembelajaran berbasis profil MBTI, Big Five, dan VARK.
- Rekomendasi konten belajar yang relevan dengan karakter dan preferensi pengguna.
- Bantuan belajar AI untuk mendukung proses belajar secara adaptif.
